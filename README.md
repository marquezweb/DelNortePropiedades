# Del Norte Propiedades

Copia mínima de la demo actual para subir a GitHub. Subir el contenido de esta carpeta a la raíz del repositorio, manteniendo los nombres y subcarpetas.

## Ejecutar localmente

Con Node.js: `npm run dev`. Abrir http://127.0.0.1:5173/. No requiere instalar paquetes ni ejecutar un build.

## Revisar la copia

`npm run check` comprueba sintaxis y que todos los archivos del manifiesto estén presentes.

## Contenido

Cuatro páginas HTML, CSS y JavaScript, datos de propiedades y desarrollos, imágenes usadas por las cards, galerías y hero, y servidor local opcional. Las fotos del hero son las originales optimizadas a WebP, sin retoques de IA. Las galerías de propiedades usan sus JPG originales.

Los mensajes de WhatsApp se preparan según la sección; el visitante los envía desde WhatsApp. No hay backend ni envío automático.

Tailwind CDN, las fuentes de Google, los iconos y el mapa necesitan conexión a Internet. Es una demo estática; guardar este código en GitHub no publica por sí solo una web.

No incluye capturas, imágenes de IA, originales de oficina pesados, fotos de publicaciones que no aparecen, ni scripts antiguos de preparación. El proyecto de trabajo conserva esos materiales y sus tests.

La lista exacta de archivos del sitio está en `upload-manifest.json`.
